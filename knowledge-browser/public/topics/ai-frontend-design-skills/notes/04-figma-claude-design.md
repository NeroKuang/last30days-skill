# Figma MCP 與 Claude Design 工作流

## Claim

「純 coding agent」常輸給設計向產品；用 Figma MCP 或 Claude Design（再 MCP 回 repo）是另一條高訊號路徑。

## Implications
- 設計系統在 Figma、實作在 Cursor：MCP 比純截圖描述穩。
- 團隊需重寫 design→dev 流程，不只換工具。
