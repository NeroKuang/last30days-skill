# Otaku 與 SillyTavern 差異

## Claim

兩者都是角色前端、都接同一本機腦；差在生態與上手成本，不決定無審查或出圖品質。

## Evidence

| | Otaku | SillyTavern（ST） |
|---|---|---|
| 定位 | 輕量角色／故事客戶端 | 角色扮演標準工作室 |
| 安裝 | 通常一指令、較少基礎設施 | Node 等，步驟較多 |
| 角色卡生態 | 較小 | **最大**（卡／世界書／分享） |
| 出圖串接 | 多半手動或自接 | 擴充多，常見接本機圖生 |
| 學習成本 | 低 | 中高 |
| 定案 | **第一週主用** | Phase 1.5 再上 |

不差在：模型強度、無審查、出圖引擎（那些是 LM Studio／Draw Things／ComfyUI）。

## Implications
- 可並存，皆指 `http://127.0.0.1:1234/v1`。
- 未出現「大量換卡／世界書」需求前，不主動改推 ST 為第一天必裝。

## Actions
1. Phase 0：只裝 Otaku。  
2. 需要社群角色卡生態時再裝 ST，並更新 `00-decision-log.md`。
